# Quanta

Quanta is a privately developed quantitative trading and research platform.

This public repository contains only the static project showcase website published at [futurebychris.github.io/Quanta](https://futurebychris.github.io/Quanta/).

## Public repository scope

The underlying Quanta trading engine, strategies, research infrastructure, datasets, model-development pipeline, brokerage integrations, configuration, and credentials are private. They are not included in this repository and are not open source.
